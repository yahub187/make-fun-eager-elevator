Entrants write the funniest one line a talking elevator could say, 120 characters at most. A judge model compares lines in pairs and the funniest takes the $2 reward.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out python3 main.py
```
